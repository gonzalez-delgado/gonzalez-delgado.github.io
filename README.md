# gonzalez-delgado.github.io

Personal academic website of Javier González-Delgado: <https://gonzalez-delgado.github.io>

The design is adapted from the [Future Imperfect](https://html5up.net/future-imperfect) theme by [HTML5 UP](https://html5up.net). It has been modified for this site.

The CV (`CV/CV_GonzalezDelgado.pdf`) is built from an adapted version of the [Awesome CV](https://github.com/posquit0/Awesome-CV) LaTeX template by Claud D. Park.
